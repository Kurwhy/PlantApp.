# 🌱 PlantApp

### Flutter Mobile Application

**PlantApp** adalah proyek aplikasi mobile yang dikembangkan menggunakan Flutter dan Dart. Aplikasi ini menampilkan antarmuka informasi barang, halaman profil, serta fitur interaktif berupa pengambilan foto melalui kamera, pemilihan gambar dari galeri, dan pemilihan lokasi.

Proyek ini dibuat untuk mengimplementasikan pengembangan antarmuka mobile serta integrasi kemampuan perangkat dalam aplikasi Flutter.

## ✨ Fitur Utama

- **Halaman Utama** — Menampilkan tampilan awal aplikasi dan informasi barang.
- **Detail Barang** — Menampilkan informasi detail barang yang dipilih.
- **Halaman Profil** — Menampilkan informasi profil pengguna.
- **Kamera & Galeri** — Memungkinkan pengguna mengambil foto atau memilih gambar dari galeri perangkat.
- **Perubahan Foto** — Menampilkan hasil foto yang dipilih pengguna.
- **Pemilihan Lokasi** — Menyediakan antarmuka untuk memilih dan menampilkan lokasi.

## 🚀 Instalasi

Pastikan Flutter SDK dan perangkat atau emulator sudah tersedia.

**1. Clone repository**

```bash
git clone https://github.com/Kurwhy/PlantApp..git
cd PlantApp.
```

**2. Instal dependency**

```bash
flutter pub get
```

**3. Jalankan aplikasi**

```bash
flutter run
```

Untuk memeriksa kesiapan lingkungan Flutter, gunakan:

```bash
flutter doctor
```

Fitur yang menggunakan kamera, galeri, atau peta mungkin memerlukan izin perangkat dan konfigurasi tambahan sesuai platform.
